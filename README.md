# Personal Portfolio

A modern, responsive, and interactive personal portfolio website built with **React** to showcase my skills and projects. The portfolio highlights my technical expertise, featured projects, and provides an easy way for recruiters and clients to get in touch.

## 🌐 Live Demo

🔗 https://personal-portfolio-woad-pi-96.vercel.app

## ✨ Features

- 🎨 Modern and responsive user interface
- 📱 Mobile-friendly design
- ⚡ Smooth animations and transitions
- 👨‍💻 About Me section
- 🛠️ Skills showcase
- 🚀 Featured projects with live demo and GitHub links
- 📄 Resume download
- 📬 Contact form powered by EmailJS
- 🌙 Clean and accessible UI
- 🔗 Social media integration

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/M-Kaif-08/Personal-Portfolio.git
```

### Navigate into the project

```bash
cd Personal-Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```
